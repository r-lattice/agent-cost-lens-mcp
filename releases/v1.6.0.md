# Agent Cost Lens v1.6.0 — more history per request, and storage that can add

*2026-07-30*

Client update: `pip install --upgrade agent-cost-lens-mcp` (1.3.1 — comment
cleanups only; 1.3.0 keeps working unchanged).

## Up to 55,000 events in one request

The per-request event limit rose from 50,000. The byte limit (15 MB) and the
event limit are now deliberately sized to meet at real record sizes: they admit
the same amount of history, so neither limit can quietly be raised past what
the other — or the server's own memory budget — allows. Ask about more history
than one request holds and the refusal still names the remedy: narrow the
window with `--since` / `--until` and repeat.

## Stored aggregates became components

The hosted tier keeps per-day aggregate figures for your key. Those used to
include stored percentages — and a stored percentage can never be re-added
across days, because its denominators are gone. Each figure is now stored as
the token counts it derives from, which makes exact whole-window recomputation
possible and clears the path for a "read back my history" feature.

Nothing about what leaves your machine changed. Same wire format, same local
pseudonyms, and `preview_upload` still shows you the exact records that would
be sent before anything is.
