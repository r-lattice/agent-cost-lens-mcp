# Agent Cost Lens v1.2.9 — reliability

*2026-07-24*

Server-side only; no client change, nothing to update on your end.

A dropped database connection could previously make the hosted service
return 500 on every authenticated call until the serving instance was
recycled. The service now reopens the connection and retries once, and its
dependencies are pinned so a rebuild can't silently change the database
client. Monitoring now probes the authenticated path directly, so this
failure class pages us instead of hiding behind a green health check.
