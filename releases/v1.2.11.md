# Agent Cost Lens v1.2.11 — beta keys can expire

*2026-07-24*

Server-side only; no client change, nothing to update on your end.

API keys may now carry an expiry. A request made with an expired key is
rejected with a clear message — "beta expired — subscribe at
lens.r-lattice.com" — instead of continuing to work silently past the beta
window. Existing keys, which carry no expiry, are unaffected.

`mint_key.py` now accepts `--expires-days N` to set a key's expiry window at
creation time.
