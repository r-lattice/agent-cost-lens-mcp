# Agent Cost Lens v1.3.0 — the consultation half, said out loud

*2026-07-26*

No client code change — `pip install` users have nothing to update. The client
tarball and README were refreshed to describe the advice layer (below); the
vendored modules are byte-identical to 1.2.11.

The product has always carried a pattern catalog on API-log runs — it names
your specific cache-waste (uncached history, cache churn, volatile prefixes)
and prices what fixing each recovers, with an honest "nothing to fix" when your
caching is already good. As of this release, the marketing surfaces finally say
so: the landing page gained an "It names the fix" section (with the
volatile-prefix advice quoted verbatim from the engine, so page and product can
never drift), and the title/meta/JSON-LD descriptions carry the same
positioning, pinned by tests.

Also in this release:
- Link-preview card (`og:image` + Twitter card) rendered at build time from the
  same constants as the page's own figures — a manifest + sha256 test fails the
  suite if the card ever goes stale against the page.
- `/robots.txt` and `/sitemap.xml`.
- Pricing: `claude-opus-5` rate card ($5/$25 per MTok, dated) — rates verified
  against Anthropic's published pricing before shipping.

As always: every recovery figure is computed from your own usage, labeled
(simulated), and the wire format still has no field for prompt text.
